# Черновик с документом или фото

Telegram не поддерживает файлы в синхронизируемых облачных черновиках. WAI хранит текст, получателя и оригинальный файл вместе; MCP умеет сохранить и прочитать этот комплект. Это **черновик в WAI**, а не вложение в поле ввода приложения Telegram. Не открывай Telegram ради прикрепления и не используй отправку себе или отложенное сообщение как замену черновика.

## Через MCP

- `save_file_draft(draft_id, chat_id, text, file_url, file_name)` скачивает файл по доступному URL и сохраняет его в WAI без обращения к Telegram
- `get_file_draft(draft_id)` возвращает текст, получателя, имя, размер, SHA-256, статус и временную ссылку на оригинал
- `list_file_drafts(chat_id?, limit?)` находит сохранённые комплекты, отдельно от текстовых `list_drafts`
- `send_file_draft(draft_id, approve=true)` отправляет сохранённый комплект только по отдельному поручению пользователя

Лимит: один файл до 10 MiB, подпись до 1024 UTF-16 символов. Используй новый UUID для новой версии; при неопределённом результате повторяй тот же ID с тем же содержимым. Существующий ID нельзя заменить другим файлом или текстом. Ключи доступа и закрытые API нельзя передавать в `file_url` вместо публично доступного или временного подписанного URL.

## Локальный файл

Не делай файл публичным. Загрузчик отправляет байты в то же закрытое хранилище, доступное через MCP, с ключом из `TELEGRAM_AI_KEY`:

```sh
python3 scripts/save_draft_file.py save --id NEW_DRAFT_UUID --chat-id VERIFIED_CHAT_UUID --file /absolute/path/contract.docx --caption-file /absolute/path/message.txt --receipt /absolute/path/draft-receipt.json
```

После загрузки вызови `get_file_draft` через MCP. Сверь `chat_id`, текст, имя, размер, SHA-256 и скачай оригинал: хеш должен совпасть с локальным файлом. Успех: `status: draft`, `has_media: true`, `sent: false`, `storage: wai_telegram`. Загрузчик также сверяет точные байты и возвращает `readback_verified: true`.

Покажи текст и ссылку на документ, назови место хранения. Если пользователь ждёт файл именно в Telegram, объясни различие; не утверждай, что он появился в приложении. При недоступности сервера сохрани локальный комплект и назови его локальным, не серверным.

## Отправка отдельно

Сохранение или исправление черновика не даёт разрешения на отправку. Только после явного поручения отправить конкретный проверенный комплект используй `send_file_draft(draft_id, approve=true)` через MCP. Эта отдельная операция отправляет сохранённые байты, требует `write` и не повторяет отправку уже опубликованного ID. При `unknown` или `publishing` сначала проверь историю адресата. После отправки сверяй сообщение через `get_message`. Открывать приложение Telegram не нужно.
