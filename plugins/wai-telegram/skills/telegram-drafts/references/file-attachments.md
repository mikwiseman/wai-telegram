# Черновик с документом или фото

Для черновика в приложении проверь текущий текст через `list_drafts`. Вызови `save_draft` с `chat_id`, точным `text`, `file_name` и одним источником файла — `file_base64` или `file_url`. Лимит одного файла 10 MiB. JPEG и PNG появятся в редакторе как фото, PDF и другие файлы — как документы. Для одного файла без подписи передай пустую строку.

Локальный файл можно прикрепить через MCP без вывода его содержимого в чат.

```sh
python3 scripts/save_draft_file.py native --chat-id CHAT_UUID --file /path/invite.pdf --caption-file /path/invite.txt
```

Проверь `saved: true`, `sent: false`, чат, текст и `attachments`. Повторное чтение через `list_drafts` покажет тот же `telegram_file_id`. При ошибке сначала перечитай черновик. Для большого числа адресатов проверь существующие черновики и сохрани чужие правки.

## Копия в WAI

Если пользователь просит отдельную копию в WAI, используй инструменты ниже.

- `save_file_draft(draft_id, chat_id, text, file_name, file_url | file_base64)` сохраняет файл по доступному URL или переданным байтам без обращения к Telegram
- `get_file_draft(draft_id)` возвращает текст, получателя, имя, размер, SHA-256, статус и временную ссылку на оригинал
- `list_file_drafts(chat_id?, limit?)` находит сохранённые комплекты, отдельно от текстовых `list_drafts`
- `send_file_draft(draft_id, approve=true)` отправляет сохранённый комплект только по отдельному поручению пользователя

Лимит: один файл любого типа до 10 MiB, подпись до 1024 UTF-16 символов. Передавай ровно один источник: `file_url` или `file_base64`. Используй новый UUID для новой версии; при неопределённом результате повторяй тот же ID с тем же содержимым. Существующий ID нельзя заменить другим файлом или текстом. Ключи доступа и закрытые API нельзя передавать в `file_url` вместо публично доступного или временного подписанного URL. Не выводи base64 файла в чат.

## Локальный файл

Не делай файл публичным. Загрузчик сам передаёт байты через MCP `save_file_draft`, читает результат через `get_file_draft` и проверяет оригинал. Ключ берётся из `TELEGRAM_AI_KEY`:

```sh
python3 scripts/save_draft_file.py save --id NEW_DRAFT_UUID --chat-id VERIFIED_CHAT_UUID --file /absolute/path/contract.docx --caption-file /absolute/path/message.txt --receipt /absolute/path/draft-receipt.json
```

После загрузки вызови `get_file_draft` через MCP. Сверь `chat_id`, текст, имя, размер, SHA-256 и скачай оригинал: хеш должен совпасть с локальным файлом. Успех: `status: draft`, `has_media: true`, `sent: false`, `storage: wai_telegram`. Загрузчик также сверяет точные байты и возвращает `readback_verified: true`.

Покажи текст и ссылку на документ, назови место хранения. Если пользователь ждёт файл именно в Telegram, объясни различие; не утверждай, что он появился в приложении. При недоступности сервера сохрани локальный комплект и назови его локальным, не серверным.

## Отправка отдельно

Сохранение или исправление черновика не даёт разрешения на отправку. Только после явного поручения отправить конкретный проверенный комплект используй `send_file_draft(draft_id, approve=true)` через MCP. Эта отдельная операция отправляет сохранённые байты, требует `write` и не повторяет отправку уже опубликованного ID. При `unknown` или `publishing` сначала проверь историю адресата. После отправки сверяй сообщение через `get_message`. Открывать приложение Telegram не нужно.
