# Wai Telegram

Шесть скиллов для повседневной работы с Telegram в Codex и Claude.

Версия 0.6.1 добавляет к отправляемым сообщениям, ответам и подписям вложений отдельную строку курсивом: «Отправлено AI-помощником.» На другом языке приписка переводится. В посте из хранилища Wai она видна уже в предпросмотре; в Избранное и обычные текстовые черновики автоматически не добавляется. Явные указания пользователя о точном тексте или приписке имеют приоритет. Это правило скилла, применяемое агентом перед отправкой; сервер сам текст не меняет.

Версия 0.6.0 добавляет отдельный `telegram-send`: сообщения, ответы, фото и файлы людям, в группы и каналы через Wai Telegram MCP. Локальные файлы загружаются скриптом плагина, затем отправляются адресату через MCP. `telegram-save` остаётся для Избранного, `telegram-drafts` — для черновиков без отправки. Интерфейс Telegram для этих действий не нужен.

Версия 0.5.0 добавляет персональные черновики для непрочитанных и ожидающих ответа, напоминания об обещанном и актуализацию старых драфтов. `save_draft` сохраняет текст без отправки. Для поста с картинкой `skills/telegram-drafts/scripts/prepare_post_draft.py` готовит локальный комплект: фото и документы Telegram не принимает как облачные черновики. Восстановление контекста включает обзор после отсутствия, поиск — подборку актуальных версий документов. Пакетное чтение из 0.3.0 сохранено: обычный разбор начинается с сообщений без обновления всего аккаунта. Сервер Wai Telegram должен предоставлять `get_inbox`, `list_drafts`, `save_draft` и `clear_draft`.

| Скилл | Примеры |
|---|---|
| `telegram-find` | «Найди смету, которую прислали весной» · «Собери актуальные документы по проекту» |
| `telegram-brief` | «Подготовь меня к встрече» · «Что я пропустил за время отпуска?» |
| `telegram-inbox` | «Кому я не ответил, включая прочитанные чаты?» · «От кого я жду ответ?» |
| `telegram-drafts` | «Сохрани черновик инструкции Грише» · «Сделай черновики всем непрочитанным» |
| `telegram-send` | «Отправь Грише подписанные PDF» · «Опубликуй пост с фото в канале» · «Напиши ему в Telegram» |
| `telegram-save` | «Отправь этот PDF мне в Избранное» · «Пришли туда итог нашей работы» |

Скиллы выбираются по смыслу запроса. В Codex их можно вызвать явно как `$wai-telegram:telegram-send`; в Claude Code — `/wai-telegram:telegram-send`. Для отправки себе аналогично выберите `telegram-save`.

Поиск, чтение и сохранение текстовых черновиков выполняются через Wai Telegram MCP, без Computer Use. Для поста с картинкой скрипт `prepare_post_draft.py` готовит локальный комплект. Фото и документы Telegram не принимает как вложения облачного черновика; комплект нельзя называть прикреплённым в Telegram. Ни отправка в Избранное, ни отложенная публикация не заменяют черновик.

## Поиск по смыслу и подборка ссылок

«Найди разговор о подготовке доклада» использует `find_chats(mode="hybrid")`, а поиск внутри найденных чатов — `search_messages(mode="hybrid")`. Для точной фразы есть `exact`. Семантическая выдача помогает найти обсуждение, но не заменяет полный перечень материалов.

«Собери все Google Docs из переписки с Алексом» использует новый серверный инструмент `get_links`: обычные и скрытые под текстом HTTP(S)-ссылки, фильтры доменов и дат, исходные сообщения и курсор продолжения. Нужно обновление MCP-сервера; установка одного архива плагина не добавляет инструмент на сервер. Пример после определения UUID чата:

```json
{"chat_id":"UUID из search_chats","domains":["docs.google.com","drive.google.com"],"max_pages":2}
```

Передавайте `next_cursor` следующему вызову как `before` с теми же фильтрами до `has_more=false`. Пустая подборка не означает конец истории. URL объединяются внутри вызова; при объединении страниц сохраняйте все исходные сообщения. Инструмент не скачивает внешние документы и читает только синхронизированную историю; её охват указан в `coverage`. Вложения перечисляет `get_files`.

## Ответы, напоминания и старые драфты

- «Сделай в Telegram черновики всем непрочитанным» — обновить unread-счётчики один раз, пройти весь выбранный список и подготовить отдельный ответ там, где он нужен.
- «Сделай черновики всем, кто ждёт моего ответа, включая прочитанные» — проверить открытые вопросы независимо от unread-статуса.
- «Подготовь черновики напоминаний тем, кто обещал прислать документы» — проверить обещания, более поздние ответы и уже отправленные напоминания.
- «Приведи в порядок старые черновики» — сверить с живой перепиской, сохранить полезное, обновить устаревшее и очистить подтверждённо закрытые вопросы.

«Что ответить» или «покажи варианты» даёт тексты в текущей задаче. Поручение создать драфты в Telegram сохраняет их без отправки; «проверь черновики» само по себе не разрешает менять их. Непрочитанное «спасибо», сообщение канала или вопрос другому человеку не равны ожидающему ответа. В итогах видны охват, сохранённые черновики и причины пропусков. Явное «всем» не сокращается до первых десяти чатов.

Существующие черновики сверяются до и после записи. Текущий MCP сохраняет текст: фото, файлы, адресация в тему форума, reply-привязка и метаданные форматирования не поддерживаются. Подготовь их локально; неподдерживаемые метаданные существующего черновика не следует молча терять. Условной атомарной записи пока нет, поэтому одновременную ручную правку нужно учитывать повторной проверкой.

## Свой Telegram и ключ

Плагин не содержит ключей или переписок. `telegram.waiwai.is` — закрытый сервер одного владельца: установка плагина не создаёт на нём новый аккаунт. Другому владельцу нужен собственный экземпляр Wai Telegram с подключённой пользовательской сессией Telegram и своим API-ключом. Не передавайте чужому человеку ключ к вашему архиву.

В среде запуска агента задайте `TELEGRAM_AI_KEY`. Для своего сервера также задайте `TELEGRAM_AI_URL`, например `https://telegram.example.org` (без `/mcp` и завершающего слеша). Для чтения достаточно `read`; для черновиков — `draft`; для отправки сообщений и файлов нужен `write`. Публикация в группе или канале также требует прав подключённого Telegram-аккаунта. Ключ не нужно вставлять в скилл, архив или чат с агентом.

В **Codex** дополнительно замените URL в `plugins/wai-telegram/.mcp.json` на адрес своего сервера с `/mcp`: Codex использует URL из файла и токен из `TELEGRAM_AI_KEY`. **Claude Code** подставляет обе переменные непосредственно из среды.

## Установка из архива

Скачайте архив нужного клиента и распакуйте его в постоянную папку. Команды ниже выполняются из корня распакованного архива; установленный плагин подключается к работающему серверу, сервер не входит в ZIP.

**Codex — `wai-telegram-codex.zip`:**

```sh
codex plugin marketplace add .
codex plugin add wai-telegram@wai-telegram-plugins
```

**Claude Code — `wai-telegram-claude.zip`:**

```sh
claude plugin marketplace add .
claude plugin install wai-telegram@wai-telegram-plugins
```

После установки начните новую задачу. Если тот же MCP уже подключён отдельно, проверьте выбранный аккаунт и отсутствие дублей перед отключением прежнего подключения.

**Claude Desktop / Cowork:** `wai-telegram-claude-plugin.zip` содержит сам плагин для пункта Upload plugin в Customize → Plugins. Работа авторизации через переменные среды в этих режимах отдельно не подтверждена: наличие ZIP не означает, что удалённый коннектор уже подключён. Для обычного веб-чата требуется настроенное совместимое подключение к MCP; загрузка локальных файлов через скрипт требует Python и доступного ключа в среде выполнения. Проверенный CLI-сценарий описан выше.

## Отправить человеку, в группу или канал

Используйте [telegram-send](skills/telegram-send/SKILL.md). Получатель определяется через `search_chats`, затем `send_message` отправляет текст, `reply_to_message` — ответ, а `send_file` — фото или документ по HTTP(S)-ссылке с подписью. Пост с одним фото и текстом в пределах 1024 символов передаётся одним вызовом `send_file`, текст — в `caption`.

Для локального файла общий загрузчик `skills/telegram-save/scripts/send_to_saved.py` сначала передаёт оригинал в Избранное и проверяет размер/SHA-256. `get_files` возвращает ссылку именно на загруженное сообщение; `send_file` отправляет вложение конечному адресату. Копия остаётся в Избранном. Завершение подтверждается сообщением у конечного получателя, а не промежуточной загрузкой. Публичный файловый хостинг не нужен.

Текущие инструменты отправляют один файл за вызов. Единый альбом, явный выбор «фото / файл», редактирование поста и отложенная публикация пока не доступны через этот MCP; скилл обозначает ограничение и не заменяет его неоговорёнными публикациями. Фото Telegram может сжать; документы можно проверить побайтово.

## Отправить себе

В MCP используйте `send_message(chat_id="me", text=...)` для текста и `send_file(chat_id="me", file_url=..., file_name=...)` для файла по ссылке. `me` всегда означает Избранное текущего аккаунта, не требует синхронизации собственного чата и не выбирает другого получателя. Файл сохраняется оригиналом с именем и расширением; текст не преобразуется из Markdown.

Локальные файлы передаются напрямую скриптом без стороннего публичного хостинга:

```sh
python3 plugins/wai-telegram/skills/telegram-save/scripts/send_to_saved.py /absolute/path/report.pdf --caption 'Готовый отчёт'
```

Скрипт использует только стандартную библиотеку Python 3.11+, передаёт файл потоком и сверяет SHA-256 и размер, возвращённые сервером. У загрузки нет дополнительного ограничения размера в плагине; действуют ограничения аккаунта Telegram, сервера и внешнего прокси. Не повторяйте отправку автоматически после обрыва связи: сообщение уже могло появиться в Избранном.

## Обновление и удаление

Распакуйте новую версию в ту же папку и повторите установку для Codex; в Claude Code выполните `claude plugin update wai-telegram@wai-telegram-plugins`. Затем начните новую задачу. Удалить плагин можно в интерфейсе клиента; в Claude Code также доступна команда `claude plugin uninstall wai-telegram@wai-telegram-plugins`. Удаление плагина не удаляет сообщения из Telegram.

## Сборка из исходников

В репозитории `mikwiseman/wai-telegram`:

```sh
python3 scripts/build-wai-telegram-plugin.py --output /absolute/path/wai-telegram-dist
```

Сборщик создаёт два установочных каталога с маркетплейсами, ZIP для каждого клиента и отдельный ZIP плагина для Claude Desktop. Содержание скиллов общее; конфигурация MCP соответствует клиенту. Версия находится в `plugins/wai-telegram/.codex-plugin/plugin.json`.

### Полный пост до approve

`telegram-drafts/scripts/post_draft.py` сохраняет картинку и Markdown-подпись в собственном хранилище Wai Telegram через API и проверяет чтением обратно. Сохранение не обращается к Telegram. Публикация — отдельная команда с `--approve` после явного поручения пользователя; полный черновик не синхронизируется с текстовым черновиком в приложении Telegram.
